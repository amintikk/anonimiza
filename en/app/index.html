Using OCR: yes

This PDF has no text that can be copied: it is a picture of the page. To read it we use OCR, a program that recognises the letters in the picture. It runs on your device and nothing is sent.

It can make mistakes: letters or numbers misread, or a data item missed. Before sharing the result, compare it with the original PDF.

How it works

  1. Paste or open a document. It does not leave this browser.
  2. Review what was detected: switch off anything that is not personal data, and select in the text anything that is missing.
  3. Copy the result with markers such as [PERSON_1] and use it wherever you like.
  4. Restore the data in the reply the AI sends back, from the “Restore” tab.

Detected data

Always review the result. Automatic detection sometimes fails and does not guarantee complete anonymisation: a job title, a place or a detail of the context can be enough to identify someone.
